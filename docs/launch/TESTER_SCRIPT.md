# Basic Tester Script (v1)

Audience: friendly first-round testers (non-technical)  
Goal: uncover friction, bugs, and payment issues quickly.

## Tester Setup

1. Install latest tester build.
2. Create account and sign in.
3. Create one new project.

## Core Path Tests

### A) Onboarding and Project Flow
- [ ] Select experience level
- [ ] Complete camper profile basics
- [ ] Open systems tab and select appliances
- [ ] Reach recommendations/build page

### B) Shop and Basket
- [ ] Open shop sections
- [ ] Add one item to basket
- [ ] Change quantity and remove item
- [ ] Re-add item and proceed to checkout

### C) Checkout
- [ ] Checkout opens in-app
- [ ] Complete payment successfully
- [ ] Confirm success screen appears
- [ ] Confirm basket clears after success

### D) Cancel / Failure Path
- [ ] Start checkout and cancel
- [ ] Confirm cancel screen appears
- [ ] Confirm basket still contains items

## UX Feedback Questions

1. What felt confusing?
2. Where did you hesitate?
3. Any screen with too much text?
4. Did you trust the checkout flow?
5. What would make you more likely to purchase?

## Reporting

Please send:
- Device model + OS
- Exact step where issue happened
- Screenshot/video
- What you expected vs what happened
- Severity: blocker / major / minor
