# Supplier API + Product Feed Request Template

Use this message when contacting dropship suppliers.

---

Subject: API/Product Feed Access Request - CamperPlan by Crafted

Hi [Supplier Name],

We are preparing launch for `CamperPlan by Crafted`, a campervan build planning app with integrated checkout and fulfilment handoff.

To align stock, pricing, and fulfilment, we need access to one of the following:

1) API access (preferred), or  
2) Scheduled product feed export (CSV/JSON).

## Data we need per SKU

- SKU / product ID
- Product name
- Category
- Description
- Image URL(s)
- Unit price (GBP, inc/ex VAT flag)
- Stock status and quantity (if available)
- Lead time / dispatch window
- Shipping profile (standard / heavy / pallet / restricted)
- Brand / model attributes
- Weight / dimensions (if available)
- EAN / barcode (if available)

## API details requested

- Base URL and endpoint list
- Authentication method (API key/OAuth)
- Rate limits
- Webhook support (stock/price updates)
- Sandbox/test environment availability
- Error format and retry guidance

## Operational model (for agreement)

- Stock ownership and liability
- Lead-time commitments
- Packaging/branding expectations
- RMA/returns flow and SLA
- Missing/damaged parcel process
- Billing and settlement cadence

If API is not available, a daily feed is acceptable for launch, with an API transition after launch.
